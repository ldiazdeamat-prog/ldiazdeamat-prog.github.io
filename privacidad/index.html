Política de privacidad

Aplicación: EJE Penal Archivo Fotografico
Última actualización: 12 de noviembre de 2026

1. Responsable y alcance

Esta política describe el tratamiento de datos por la herramienta de escritorio EJE Penal Archivo Fotografico, administrada para uso propio por Luis Díaz. Para consultas sobre privacidad: ldiaz.pmsjpenal@gmail.com.

La herramienta se ejecuta en la computadora del usuario. Este sitio informativo no es el panel local del programa ni almacena el archivo fotográfico.

2. Datos que utiliza el programa

  • Fotografías RAW y JPG de las carpetas locales que el usuario configura y de los eventos de Drive que solicita procesar.
  • Metadatos de las fotografías, como fecha de captura, orientación y sensibilidad ISO.
  • Nombres, identificadores y estructura de las carpetas y archivos de Google Drive, tamaños y sumas de comprobación para verificar las transferencias y detectar conflictos.
  • Información de autorización de Google necesaria para mantener la conexión, incluidos tokens de acceso y renovación.
  • Registros de estado, fechas de eventos, decisiones de selección, miniaturas y rutas locales necesarias para continuar el trabajo y evitar reprocesamientos.

3. Finalidad del acceso

Los datos se utilizan para detectar sesiones nuevas, evaluar calidad y similitud entre tomas, aplicar la edición aprobada, exportar JPG y organizar los originales y entregables en las carpetas de EJE Penal indicadas por el usuario.

El análisis puede detectar rostros para evaluar enfoque o ajustar la luminosidad. No identifica a las personas ni crea un registro de identidades faciales.

Los datos no se utilizan para publicidad, venta de información, creación de perfiles comerciales ni entrenamiento de modelos de inteligencia artificial.

4. Autorización de Google Drive

El usuario concede acceso mediante la pantalla oficial de Google. La aplicación solicita el permiso https://www.googleapis.com/auth/drive, que permite acceder a archivos de la cuenta. Este alcance se necesita para encontrar y utilizar carpetas y archivos existentes, además de crear eventos, renombrar carpetas de trabajo, descargar RAW y subir los resultados.

Dentro del programa, los destinos se restringen a la estructura de EJE Penal configurada. El alcance de la autorización de Google es más amplio que esa restricción del programa. El usuario puede revocarlo en las conexiones con aplicaciones de su cuenta de Google.

Las contraseñas de Google y los códigos de verificación no se solicitan ni se guardan en el panel local.

5. Dónde se procesan y guardan los datos

El revelado fotográfico y la selección se realizan localmente en Windows. El programa se comunica con Google para autorizar y renovar el acceso y para consultar, descargar y subir archivos a Google Drive.

En la computadora se conservan los resultados, miniaturas, informes, caché de descargas, configuración y credenciales de acceso del programa. En Drive se conservan los archivos de las carpetas elegidas por el usuario. Estos datos no se envían al alojamiento de esta página informativa.

Las credenciales se guardan en archivos locales del programa. El usuario debe proteger su sesión de Windows y restringir el acceso a esa carpeta. No deben publicarse esos archivos ni incluirse en un repositorio web.

6. Comunicación de datos a terceros

El programa transmite a Google los datos necesarios para ejecutar las operaciones de Drive solicitadas. No envía fotografías a servicios externos de generación o edición mediante IA y no comparte el archivo fotográfico públicamente.

Los datos de los servicios de Google están sujetos a las políticas de Google. Si el usuario comparte archivos por otras aplicaciones o mediante un chat, esas acciones son independientes del flujo automático descrito aquí.

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de Uso Limitado.

7. Conservación y eliminación

El programa no borra automáticamente los originales ni las fotografías descartadas. Los archivos locales de trabajo, caché e informes permanecen hasta que el usuario los elimine. Los archivos subidos a Drive permanecen hasta que el usuario gestione su eliminación en Drive.

Para desconectar la aplicación, el usuario puede revocar el acceso en Google y retirar sus credenciales locales. Eliminar las credenciales detiene la conexión, pero no borra las fotografías ya guardadas. Para consultas o asistencia sobre acceso, rectificación o eliminación de datos, utiliza el correo de contacto de esta política.

8. Datos de este sitio informativo

Estas páginas no incluyen formularios, publicidad, herramientas de seguimiento analítico ni una conexión a Drive. El proveedor de alojamiento puede registrar información técnica de las visitas, como dirección IP, navegador y momento de acceso, para prestar y proteger su servicio, conforme a sus propias políticas.

9. Cambios y contacto

Si cambia el funcionamiento del programa o el uso de los datos, se actualizará esta política y su fecha. Las consultas pueden enviarse a ldiaz.pmsjpenal@gmail.com.
